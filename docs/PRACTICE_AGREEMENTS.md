# Practice agreements

Use "New practice agreement" in Admin > Agreements to rehearse the whole flow (send link, code, every signature method, countersign, sealed PDF).

- Numbered TEST-YYYY-NNNN (real BHC numbers are never used up).
- Hidden from the normal list; tick "Show practice" to see them.
- Marked PRACTICE on the signing page, the PDF and the certificate; emails get a "[PRACTICE]" subject prefix; no staff alert emails.
- The sealed PDF goes to the normal private bucket, never the locked signed bucket, so it can always be deleted.
- Can be deleted at any status. "Delete all practice" removes every one. Practice agreements are also deleted automatically after
  AGREEMENT_PRACTICE_RETENTION_DAYS (default 3).
- Use your OWN email/phone as the client contact. SMS has no practice label, so do not send practice links to real clients.

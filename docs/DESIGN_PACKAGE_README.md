# Well Nest Home Care Uganda: design package

Start with `docs/NEST_HOME_CARE_BUILD_SPEC.md` for functional requirements and implementation scope.

**Canonical UI reference:** open `reference/nest-all-features-mockups.html` first. It defines the intended page sections, design language, navigation groups and responsive behaviour for the public website, nurse app and admin. Use `docs/UI_REFERENCE_GUIDE.md` for the mapping from the reference to implemented routes and for local UI-test commands.

`reference/nest-home-care-complete.html` and `reference/nest-full-site-preview.html` are earlier/supplementary previews. They may help where the canonical mockup does not show a detail, but must not override it on UI decisions. The build specification and security/access-scope rules continue to govern functional behaviour.
